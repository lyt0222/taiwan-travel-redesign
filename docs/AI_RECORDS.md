# AI 使用紀錄整理指引

本文件是待填的整理架構，**不是已完成的十組 AI 使用紀錄**。請從實際開發對話取得截圖，不能補造提問、AI 回覆、錯誤過程或執行成果。

每組需包含：實際輸入 Prompt 的對話截圖、使用目的、AI 回覆與結果，以及對應網站畫面或功能執行結果。對話截圖需清楚可讀，並遮蔽密碼、資料庫連線字串及金鑰。

| 組次 | 可採用的實際開發階段 | 建議對應成果 | 紀錄狀態 |
| --- | --- | --- | --- |
| 01 | 需求整理與網站架構 | 頁面及資料流程規劃 | 待補真實截圖 |
| 02 | 共用樣式與手機排版 | 桌面／手機版畫面 | 待補真實截圖 |
| 03 | 首頁與文字導覽 | 首屏查詢與任務入口 | 待補真實截圖 |
| 04 | 搜尋與多條件篩選 | 單條件、交集、無結果 | 待補真實截圖 |
| 05 | Django 資料模型與 Admin | 模型與後台管理畫面 | 待補真實截圖 |
| 06 | View、URL 與 Template | 後台資料顯示在前台 | 待補真實截圖 |

以上是收集方向，應以實際對話內容調整；如果十個階段並未各自產生實際提問，不能將同一段對話重新改寫成十組。可將後續真正發生的改版、除錯與部署對話納入。
