## 本機自動化驗收結果

驗證日期：2026 年 10 月 29 日。環境：Windows、Python 3.13、Django 5.2.18、SQLite。

- Django 整合與安全測試：25 項全部通過。涵蓋多條件交集、縣市精確篩選、登入／註冊／登出、個人收藏隔離、收藏不重複、POST 與 CSRF 保護、安全的登入後跳轉、HTML 跳脫、管理後台編輯反映前台，以及重複載入示範資料保留既有修改。
- 真實本機伺服器：已啟動 `http://127.0.0.1:8000/`，首頁、景點列表、會員登入、管理員登入與 CSS、JavaScript、本機插畫資源的 HTTP 回應均為 200。
- 真實 HTTP 操作流程：8 項全部通過，涵蓋首頁、精確縣市查詢、帶 CSRF 與 Session 的會員登入、收藏後可見、取消收藏後消失、登出、Admin 登入及後台景點列表。
- JavaScript 互動測試：4 項全部通過，涵蓋大字模式的還原與保存、localStorage 受阻時仍可切換、手機選單／Escape／焦點／回到桌面寬度時收合，以及密碼顯示切換。測試使用 Node.js VM 與模擬 DOM 執行正式腳本，**不是瀏覽器或實際排版驗收**。
- 網頁視覺驗收：真實瀏覽器桌面／手機畫面尚未完成目視檢查，響應式排版與大字模式仍需依下方清單人工確認，不能視為通過。
- Neon、Render、教師測試帳號、真實 AI 截圖與簡報 PDF 尚未完成，均未以本機測試代替。

## 本機手動驗收清單

- 首頁、列表、詳情、登入、註冊、收藏與後台可開啟。
- 縣市篩選不將外縣市景點混入結果；關鍵字與所在地是不同條件。
- 關鍵字、縣市與主題採交集，無結果時有說明且可清除條件。
- 卡片顯示縣市及鄉鎮區，詳情提供官方來源。
- 登入失敗有提示；會員可登入、登出。
- 收藏需登入、重複收藏不建立重複資料、不同會員的收藏互不混用。
- 未授權收藏寫入與缺少 CSRF token 的 POST 請求不應成功。
- 後台新增、修改及刪除資料後，前台可對應更新。
- 大字模式跨頁維持；手機版導覽、表單與卡片沒有水平溢出。
- 查詢條件及使用者輸入以 Django 模板自動跳脫，登入後跳轉不能導向外部網站。
